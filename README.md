# Модель задачи N тел с гравитационным взаимодействием

## Описание

Программа моделирует динамику системы из N точечных частиц, взаимодействующих по закону всемирного тяготения. Реализованы два метода вычисления сил:

- Прямое суммирование (Particle–Particle, PP) — сложность O(N²), используется как эталон точности.
- Метод дерева Барнса–Хата (Barnes–Hut) — сложность O(N log N), применяется для больших N.

Для интегрирования уравнений движения используются симлектические схемы:

- Метод Верле (4-й порядок по координате, 2-й по скорости).
- Метод leap-frog (перешагивание).

Поддерживаются периодические граничные условия и смягчение потенциала (softening) для устранения сингулярности при r → 0.

Программа основана на материалах лекции №6 «Методы динамики частиц» и использует численные схемы, рассмотренные в лабораторной работе по газовой динамике.

## Логика работы

1. Инициализация системы — генерация N частиц с массами, начальными положениями и скоростями. По умолчанию создаётся вращающийся диск (2D) или сфера (3D) с круговыми скоростями вокруг общего центра масс.

2. Вычисление ускорений — на каждом шаге по времени для каждой частицы вычисляется ускорение:
   - при `use_tree=False` — прямое суммирование;
   - при `use_tree=True` — обход дерева Барнса–Хата с критерием s/d < θ.

3. Интегрирование по времени — одним из симлектических методов:
   - Верле: r(t+Δt) = 2r(t) − r(t−Δt) + Δt² a(t);
   - leap-frog: v(t+Δt/2) = v(t−Δt/2) + Δt a(t), r(t+Δt) = r(t) + Δt v(t+Δt/2).

4. Периодические граничные условия — если координата выходит за пределы ячейки [0, L]^D, она заворачивается: r ← r − L ⌊r/L⌋.

5. Контроль энергии — на каждом шаге вычисляется полная энергия E = K + U для проверки качества интегрирования.

6. Визуализация — анимация движения частиц (только для 2D) и график относительной полной энергии E(t)/E(0).

## Математическая модель

Уравнение движения:

m_i dv_i/dt = F_i,   dr_i/dt = v_i

Гравитационная сила:

F_i = G Σ_{j≠i} m_i m_j (r_j − r_i) / (|r_j − r_i|² + ε²)^{3/2}

Потенциальная энергия:

U = −G Σ_{1≤i<j≤N} m_i m_j / |r_j − r_i|

Критерий Barnes–Hut: группа частиц заменяется одной фиктивной, если s/d < θ, где s — размер ячейки, d — расстояние до центра масс группы.

## Структура программы

### Функции и классы

| Компонент | Назначение |
|-----------|------------|
| `accelerations_direct(pos, mass, G, eps, L)` | Прямое вычисление ускорений всех частиц (O(N²)). Учитывает периодические границы, если задан L. |
| `OctreeNode` | Класс узла октодерева: хранит центр ячейки, размер, суммарную массу, центр масс, детей и индексы частиц. |
| `build_tree(pos, mass, center, size, indices, max_per_leaf)` | Рекурсивное построение дерева. |
| `accel_from_tree(node, pos_i, G, theta, eps)` | Вычисление ускорения одной частицы обходом дерева. |
| `accelerations_bh(pos, mass, G, theta, eps, root_size)` | Вычисление ускорений всех частиц методом Барнса–Хата. |
| `wrap(pos, L)` | Заворачивание координат в периодическую ячейку. |
| `leapfrog_step(pos, vel, mass, dt, G, eps, use_tree, theta, L)` | Один шаг интегратора leap-frog. |
| `verlet_step(pos, pos_prev, mass, dt, G, eps, use_tree, theta, L)` | Один шаг метода Верле. |
| `total_energy(pos, vel, mass, G, eps, L)` | Вычисление кинетической, потенциальной и полной энергии. |
| `init_disk(N, D, seed, G)` | Генерация начальных условий: диск (2D) или сфера (3D) с круговыми скоростями. |
| `run_simulation(...)` | Основной цикл интегрирования. Возвращает траекторию и массив энергий. |
| `animate(trajectory, interval, L_lim)` | Анимация движения частиц (2D). |
| `plot_energy(energies)` | График сохранения энергии. |
| `compare_pp_bh(N, D, theta, eps, seed)` | Сравнение точности Barnes–Hut с прямым суммированием. |
| Блок `if __name__ == "__main__":` | Запуск сравнения, симуляции, визуализации. |


## Параметры

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `N` | 300 | Число частиц |
| `D` | 2 | Размерность пространства (2 или 3) |
| `steps` | 600 | Число шагов по времени |
| `dt` | 0.005 | Шаг по времени |
| `G` | 1.0 | Гравитационная постоянная |
| `eps` | 0.05 | Параметр смягчения (softening) |
| `theta` | 0.5 | Порог критерия Barnes–Hut s/d < θ |
| `use_tree` | `False` | Использовать дерево (True) или прямое суммирование (False) |
| `integrator` | `"verlet"` | Интегратор: `"verlet"` или `"leapfrog"` |
| `seed` | 42 | Зерно генератора случайных чисел |
| `L` | `None` | Размер периодической ячейки (None — без периодичности) |

## Настройка


```bash

N          = 300
D          = 2
steps      = 600
dt         = 0.005
G          = 1.0
eps        = 0.05
theta      = 0.5
```

## Визуализация
Анимация: чёрный фон, белые точки-частицы, заголовок с текущим номером шага.

График энергии: почти горизонтальная линия E(t)/E(0) — признак хорошего сохранения энергии. Отклонение обычно < 0.01% при симлектических интеграторах.

## Ограничение модели
Не учитывает релятивистские эффекты.

Не моделирует столкновения и слияния тел.

Не учитывает внутреннюю структуру, вращение и деформацию тел.

Не учитывает трение, сопротивление среды и негравитационные силы.

Не является точной моделью реальных астрофизических систем.

Метод Barnes–Hut даёт приближённые силы (ошибка ~0.1–1% при θ=0.5).

Фиксированный шаг по времени при близких сближениях даёт накопление ошибок.
